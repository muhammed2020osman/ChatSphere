# PWA Icons

This directory should contain the following PWA icons:

- `icon-192x192.png` - 192x192 pixels, PNG format
- `icon-512x512.png` - 512x512 pixels, PNG format

## Generating Icons

You can generate these icons from a source image (e.g., logo.png) using tools like:
- Online: https://realfavicongenerator.net/
- CLI: `npm install -g pwa-asset-generator`
- ImageMagick: `convert logo.png -resize 192x192 icon-192x192.png`

The icons should be:
- Square (1:1 aspect ratio)
- PNG format with transparency support
- High quality for best appearance on all devices

## Temporary Solution

For development, you can create simple placeholder icons using any image editor or online tool.
