# ChatSphere - Next.js App

This is a Next.js application deployed on Vercel.

## Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm run dev

# Build for production
pnpm run build

# Start production server
pnpm run start
```

## Tech Stack

- Next.js 14.2.33
- React 18
- TypeScript
- Tailwind CSS
- MySQL with Drizzle ORM

## Deployment

This project is configured for Vercel deployment with automatic detection of Next.js framework.
